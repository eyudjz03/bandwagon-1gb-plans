## 1GB 内存够用吗？以建站为例

轻量用途够用，边界在访客量。

可以先拿常见建站环境的最低要求做个参照。宝塔、LNMP、LAMP 这三类面板环境，综合下来的门槛大约是 1 核 CPU、512MB 内存、5GB 硬盘——LNMP 号称 128MB 内存也能装，但只能配很旧版本的 MySQL 和 PHP，旧版本停止维护后随时可能出安全问题。想跑最新版的 MySQL 和 PHP，最低配置就是 1 核 / 1GB / 10GB。对照搬瓦工的 1GB 套餐：内存刚好达标，20GB SSD 还留了不小的余量。

访客量方面，长期写搬瓦工教程的站点给过一个经验值：1GB 方案撑一天几百个 IP 的个人博客没问题；日 IP 上千就该考虑 2GB 起步、核数更多的方案。另外搬瓦工对 CPU 使用有限制，不允许长期跑满，指望它扛高负载应用不现实。

流量也提一句。1GB 三款套餐每月都给 1TB，纯文字博客基本用不完；图片多或者提供文件下载的，先估算月用量再决定买哪档。确定用途就是建站或学习的话，👉 [年付 $49.99 开通 1GB / 1TB 流量套餐](https://bwh81.net/aff.php?aff=77528&pid=44) 就已经够起步了，不必急着加配置。
